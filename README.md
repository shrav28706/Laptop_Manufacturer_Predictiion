# Laptop Manufacturer Prediction Using Machine Learning

## Project Description
This project predicts the manufacturer of a laptop based on its technical specifications using Machine Learning algorithms.

## Algorithms Used
- ID3 Decision Tree
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

## Dataset
The project uses `laptops.csv`, which contains laptop specifications and manufacturer information.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Evaluation Metrics
The models are evaluated using classification performance metrics and confusion matrices.

## How to Run
1. Download the repository.
2. Open the `.ipynb` file in Google Colab.
3. Ensure `laptops.csv` is available in the same working directory.
4. Run all notebook cells.
